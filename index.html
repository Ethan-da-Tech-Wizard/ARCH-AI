From booted ISO to a usable system

This guide is written for a person who may be looking at the Arch installer on one computer and reading this walkthrough on a phone, tablet, or second monitor. Every command is treated as something worth explaining.

The install order and technical facts are anchored to official Arch sources. This app adds beginner explanations, command word maps, checkpoints, and failure notes around those sources.

Source policy

Arch first, explanations second

Each lesson links back to ArchWiki, Arch manual pages, or official Arch package pages. When the Arch docs change, the walkthrough should be checked against those links before the app text is changed.
